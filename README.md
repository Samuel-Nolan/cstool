# CSTool

CSTool 是一份围绕开发环境、命令行与常用工具的个人学习笔记和实践教程。

我会查阅软件官方文档、网络教程和社区讨论，再结合自己的安装配置、实际使用与问题排查经历，对信息进行筛选、归纳和补充，整理成便于回看与复用的个人总结。这里不是任何软件的官方手册，也不以转载原文为目的；遇到适用的原始资料时，会尽量保留链接，方便读者进一步核对。

## 在线阅读

文档网站：[samuel-nolan.github.io/cstool](https://samuel-nolan.github.io/cstool/)

## 内容

- [01 环境配置](docs/01-环境配置/)：Python、Conda、uv、Git、Linux、WSL、Docker，以及 Codex、Claude Code 等工具的环境配置。
- [02 工具](docs/02-工具/)：AI 工具、知识管理、资料整理、Git 工作流、PPT 制作及其他实践记录。

## 阅读说明

笔记中的命令、路径和配置可能依赖特定的操作系统、软件版本或个人环境。实际操作前请结合自己的环境，并优先查阅对应工具的最新官方文档；社区经验和个人结论也应根据具体情况判断。
