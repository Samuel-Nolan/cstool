# 域名注册

## 购买

1. Cloudflare
2. Spaceship
3. Namespce

## GitHub Pages

1. 进入你的 GitHub 个人主页仓库：`Settings → Pages → Custom domain`
2. 勾选 `Enforce HTTPS`

### Enforce HTTPS

`Unavailable for your site because your domain is not properly configured to support HTTPS`

如果出现了以上失败（TLS 签发失败），点击 `Remove`，重新 `Save`。
