### 修改数据存储位置

默认存储在 C 盘（`C:\Users\用户名\Zotero`）：

1. 在其他盘新建 `/Zotero_Data`
2. 在“编辑 → 设置 → 高级”中，自定义数据位置
3. 把默认文件夹里的所有数据复制进 `/Zotero_Data`，不是整个文件夹复制
4. 删除 `C:\Users\用户名\Zotero` 这个文件夹

### 插件市场 Add-on Market for Zotero

不用再去下载单独插件安装，直接在 Zotero 中就可以更便捷地下载插件。

下载完成后，点击右侧小齿轮，选择 `Install Plugin From File`。

### 翻译 - Translation for Zotero

#### 修改翻译字体大小

- 点击顶部菜单 编辑 → 设置。
- 在设置页面左侧找到 Translate。
- 进入 User Interface（用户界面）。
- 找到 Font Size（字体大小），默认值是 `12`。可以先尝试 `18`，如果还小，再调到 `20` 或 `22`。
- 找到 Line Height（行高），建议先设为 `1.6`。

#### 关闭阅读器选词弹窗

这样选中文字后，翻译结果就只显示在右侧条目面板中，而不是悬浮翻译框。
