# CSTool

这里记录我在学习、配置和使用开发工具过程中的经验与备忘。

内容来自对软件官方文档、网络教程和社区讨论的阅读与整理，并结合个人的安装配置、实际使用和问题排查经历，筛选、归纳后写成个人总结与实践教程。CSTool 不是任何软件的官方手册，也不以原文搬运为目的；适用时会保留原始资料链接，便于进一步查阅和核对。

## 内容概览

### 01 环境配置

这一部分关注“工具如何安装和运行”，包括：

- Python、pip、Conda、uv 和 PyTorch 环境
- Git、GitHub、Node.js 和 npm
- Linux 常用命令、PowerShell、WSL 和 Jupyter Notebook
- Docker、Docker Compose 和 VPS 基础环境
- Claude Code、Codex 等 AI 编程工具的客户端配置
- Markdown、oh-my-posh 等日常开发辅助配置

### 02 工具

这一部分关注“工具如何使用和组合”，包括：

- Claude Code、MCP、Pi 和 AI coding workflow
- NotebookLM、Prompt 和资料整理方法
- Obsidian、Zotero、EndNote、RSSHub 等知识管理工具
- Git 工作流与仓库协作
- PPT 制作、PDF 转换和资料合并
- Hermes-VPS、draw.io 等其他实践工具

## 使用方式

这些内容是资料阅读与个人实践相结合的总结。命令、路径和配置项可能与操作系统、软件版本或个人环境有关，使用前请根据自己的环境调整。

如果发现内容已经过时，优先结合对应工具的最新官方文档确认；社区讨论和个人经验也请结合具体情况判断。
